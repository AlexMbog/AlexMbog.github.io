# 📱 Mobile UI Projects

A showcase of React Native and mobile UI layouts designed for smooth navigation, modern styling, and clean component structure.

### 🛒 *Mama Mboga / Groceries App UI*  
A modern **food & grocery ordering application** built for local fruit and vegetable vendors (Mama Mboga).  
It features:

- Clean React Native UI with Expo  
- Category-based browsing (vegetables, fruits, chopped groceries)  
- Product cards with images, prices, and quantity selectors  
- A seamless ordering flow designed for local Kenyan grocery markets  
- Tailwind-based styling using NativeWind  
- Designed for both Android & iOS
