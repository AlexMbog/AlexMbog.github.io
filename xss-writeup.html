⚡ Stored XSS Exploitation

Exploiting a persistent cross-site scripting vulnerability in a comment system.

XSS Stored Web Security Burp Suite

🎯 Target Overview

The application allows users to post comments which are rendered to all visitors. User input is stored and displayed without proper sanitization.

🐞 Vulnerability

User-controlled input is inserted into the HTML response without encoding, allowing execution of arbitrary JavaScript.

<p>User comment: [INPUT]</p>

🧪 Step 1: Identify Injection Point

Submitted a basic payload to test if input is reflected in the response.

test123

🧪 Step 2: Test for Script Execution

Injected a script tag to verify if JavaScript execution is possible.

<script>alert(1)</script>

✔ Payload executed successfully

🧪 Step 3: Context Analysis

Determined that input is placed directly inside HTML context, allowing full script injection.

🧪 Step 4: Payload Optimization

Used alternative payloads to bypass filters and ensure reliability.

<img src=1 onerror=alert(document.domain)>

💥 Impact

  • Session hijacking
  • Cookie theft
  • Defacement

🛡️ Mitigation

  • Output encoding
  • Input validation
  • Use of CSP headers
